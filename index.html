Tokenizer

how a language model reads text

Language models never see letters. Text is first cut into tokens, sub-word pieces with an id each, and the model only ever works with those numbers. Type below and watch it happen. Then try the Hungarian sample: every accented letter falls back to its own byte-level token, so Hungarian text costs noticeably more tokens than English.
